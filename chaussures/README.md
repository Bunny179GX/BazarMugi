# Photos des chaussures

Créer un sous-dossier par paire en utilisant son identifiant court.

Exemple :

```text
chaussures/
└── crampons-adidas-x/
    ├── 01-principale.jpg
    ├── 02-cote-gauche.jpg
    ├── 03-cote-droit.jpg
    ├── 04-dessus.jpg
    ├── 05-semelles.jpg
    ├── 06-etiquette-pointure.jpg
    └── 07-defaut.jpg
```

La première image sera utilisée sur la carte du catalogue. Les autres seront visibles dans la fiche détaillée.
